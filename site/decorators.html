Decorators reference

Every decorator → its dsh surface.

The bridge exposes nine decorators. Each one maps a Python capability to a specific surface of the deepseek-harness plugin contract. Pick the row that matches what you want to expose — the table is the contract.

The capability mapping

Python decorator Codegen target / dsh surface Parameters
@service(name, settings_namespace=None) class XxxService extends Service — mounted as ctx.<name>; other plugins can inject it. name (str), settings_namespace (str | None)
@provide_method(timeout_ms=None, is_concurrency_safe=None) Typed TS method that forwards the call into bridge.call on the Python child. timeout_ms (int | None), is_concurrency_safe (bool | None)
@tool(name, description, parameters, ...) ctx.tools.register(defineTool({...})) — model-facing tool with JSON-Schema parameters. name, description, parameters (dict), ...
@on(event, mode='emit', prepend=False, global_=False) ctx.on(event, handler, { mode, prepend, global }) — typed event listener. event (str), mode (str), prepend (bool), global_ (bool)
@capability(seam, backend) ctx.<seam>.backend.register(backend, impl) — replacement provider for a capability seam. seam (str), backend (str)
@method(name=None) A method on a capability backend class. name (str | None)
@system_prompt_section(order, text) ctx.systemPrompt.section({ order, text }) — contribution to the agent's system prompt. order (int), text (str)
@guard() ctx.tools.guard(fn) — tool-policy hook. (none — decorator form)
@restrict_tools(allow=None, deny=None) ctx.tools.restrict({ allow, deny }) — allow/deny lists applied to model tool calls. allow (list[str] | None), deny (list[str] | None)

What ships vs. what's parsed-but-not-yet-emitted

Today, the codegen emits code for the first four rows (@service, @provide_method, @tool, @on). The remaining five rows are parsed and recorded in the IR but don't yet produce generated code — see Roadmap for the current sequencing.

Error envelope

Every Python exception raised inside a decorated method is translated into a JSON-RPC error with a stable code and a data.kind. The TypeScript side maps these back into the same categories a hand-written plugin would produce.

Python exception JSON-RPC code data.kind
TimeoutError-32001timeout
asyncio.CancelledError-32002abort
PermissionError-32003permission
ValueError-32004invalid-args
KeyError / AttributeError-32005not-found
ConnectionError-32010bridge-down
any other-32603exception
process exit during call-32011worker-exit
