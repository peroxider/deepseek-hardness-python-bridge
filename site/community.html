  • Issues — bugs, use cases, feature requests
  • Pull requests — contributions welcome

Reproduce every claim on this site

The whole stack is reproducible offline. From the repo root: 

# 43 pytest + 55+ E2E assertions + generated-package lifecycle
node scripts/verify.mjs

# Browse the site you are reading right now
python3 -m http.server -d site 8000

That's it. No secrets, no install scripts, no remote dependencies. If a claim on this site doesn't hold up after running the above, it's a bug — please open an issue.

Contributing

The bridge follows the project's normal contribution flow:

  1. Open an issue first. Almost everything in Roadmap → In progress started as one user's concrete use case. A short description of your Python module and the capability surface you want to expose goes a long way.
  2. Read the human-engineer guide. It covers the verification pipeline end-to-end.
  3. Make the change small. New decorators, new flags, new parser branches — each one is its own PR.
  4. Run node scripts/verify.mjs before sending the PR. CI runs the same suite.
